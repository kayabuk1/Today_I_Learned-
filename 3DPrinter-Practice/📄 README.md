# Raspberry Pi Case - Practice 

## 概要
このフォルダは、3DCAD（Fusion 360）の基本操作および3Dプリンターでの出力手法を学ぶために作成したデータの記録用です。
今のところRaspberry Pi 用ケースの練習用3Dデータ（.f3d）のみです。

## 設計の経緯と工夫
Raspberry Pi 用ケースの練習用3Dデータ（.f3dについて
- インロー構造（三段構造）: 箱底、中蓋、箱蓋の3つのパーツが重なり合う構造を採用し、組み立てやすさを意識いたしました。

- **寸法のスケールミス**: 最初、縮尺を誤って巨大なサイズでモデリングしてしまい、スライサーソフト上で壁が薄くなりすぎる問題が発生しました。履歴を遡っての修正が困難だったため、モデル全体を縮小した後に再度壁に厚みを持たせる（肉付けする）という別のアプローチで修正を行いました。
- **3Dプリント時のトラブル**: ABS樹脂の反りや、PET樹脂のノズル詰まりといった現象に直面しました。これに対しても、プラットフォームの温度調整や印刷スピードの変更など、スライサーの設定を少しずつ変えながらテスト印刷を繰り返すことで、なんとか形にすることができました。
