■課題3：７セグメントLED表示回路
基本構造：タクトSW⇒チャタ防止⇒カウンタIC⇒デコーダIC⇒7セグ
タクトスイッチでカウント、チャタ防止
カウンタIC：7490,7493,74160,74162,74190,74191,74192,749193 いずれか
デコーダ：7447A.Cｱﾉｰﾄﾞｺﾓﾝ,7448K.Cｶｿｰﾄﾞｺﾓﾝ どちらか
７セグ：NARG105A.C※2色なので切り替え機能も搭載すること、OSL10561-LRAK.C、A-551SRDA.C いずれか
DIP-SW８P：1-4：制御機能用、5-8：4bit任意数値入力用
※チャタリング防止機能について：
⇒タクトスイッチ使用するとチャタリングは最大10msは起きる。
⇒ローパスフィルターも入れる→10kオーム*0.1uFコンデサでRC時定数を計算すると10*10^3*0.1*10^-6=10^-3
⇒シュミットトリガー回路もはさむこと。
⇒D-FF:HC7474を使ってCLKにタクトスイッチの入力信号を入れるとのこと。
⚠デコーダとカウンタ制御機能を確認できること。※_LOADに入力されたex:1011等の信号が出力としてラッチされる。ので、DIPスイッチDS08などで「今何の信号が入れられたか」結果として「何の信号が出力されたか」が分かるようにしておくとのこと。
